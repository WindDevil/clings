# 参考书阅读笔记

这份笔记记录每本参考书对 `clings` 课程设计的直接启发。原始书籍和
Markdown 位于 `.ref/books` 与 `.ref/markdown`；扫描版书籍的完整 OCR
状态见 `.ref/OCR-REQUIRED.md`。

## C 语言核心

### C 程序设计语言（第 2 版）

路径：`.ref/markdown/C/C程序设计语言（第2版）.md`

- 第 1 章用大量小例子建立“程序 = 声明 + 定义 + 控制流”的直觉。
- 第 2-3 章覆盖类型、运算符、控制流，适合作为 `00`-`03` 主题的骨架。
- 第 4-6 章覆盖函数、指针/数组、结构体，是当前 `04`-`08` 主题的主要来源。
- 第 7-8 章覆盖标准 I/O 和 UNIX 系统接口，提示需要新增文件描述符、
  `open/read/write`、`fork/exec` 等系统编程练习。
- 附录 B 是标准库清单，适合用来补 `14_stdlib_depth`。

### C Primer Plus 第 6 版

路径：`.ref/markdown/C/C Primer Plus 第6版 中文版（史蒂芬·普拉达）.md`

- 第 1 章给出编译、链接、目标文件、可执行文件、库的完整流程。
- 第 3 章覆盖 `_Bool`、`stdint.h`、`inttypes.h`、复数类型，提示补充
  `stdbool`/`stdint`/复数/浮点分类。
- 第 4、8、11、13 章覆盖字符串、字符 I/O、字符串函数、文件 I/O 的细节，
  当前项目只覆盖了其中一部分。
- 第 12 章把存储类别、链接和内存管理放在一起，是新增
  `13_translation_units` 的直接依据。
- 第 15 章位操作提示补充位域、掩码、二进制表示和端序。
- 第 16 章预处理器和 C 库提示补充宏、条件编译、标准库深度。
- 第 17 章高级数据表示提示新增动态数组、链表、队列、树、哈希表等练习。

> 本轮已经按这些缺口新增 `13_translation_units` 至
> `19_modern_c_library` 七个主题，逐章结果见
> [c-primer-plus-coverage.md](c-primer-plus-coverage.md)。

### C 陷阱与缺陷

路径：`.ref/markdown/C/C陷阱与缺陷.md`（扫描版，需 OCR）

- 主题按词法陷阱、语法陷阱、语义陷阱、链接、库函数、预处理器、
  可移植性组织。
- 当前项目已经覆盖了部分词法/语法/语义陷阱，但缺少链接、库函数边界和
  可移植性系统练习。
- 建议新增：`sizeof`/类型提升陷阱、声明/定义不匹配、`extern` 链接错误、
  库函数返回值和错误码、整数宽度和字节序。

### C 语言接口与实现

路径：`.ref/markdown/C/C语言接口与实现.md`（扫描版，需 OCR）

- 核心是“接口与实现分离”，以及用 C 实现 ADT。
- 典型章节包括内存管理、列表、表、集合、位向量、异常、线程、文本和
  环形缓冲区。
- 当前项目只有链表；建议按这本书的思路新增
  `16_data_structures`，并加入不透明类型、接口头文件、实现文件和
  资源所有权练习。

### C 专家编程

路径：`.ref/markdown/Algorithms/C专家编程.md`（扫描版，需 OCR）

- 重点包括声明语法、数组和指针、链接、内存、预处理器、ANSI C、
  优化、可移植性。
- 还讨论 `setjmp`、`volatile`、`const`、`restrict`、`inline`、`#pragma`、
  调用约定、字节序、对齐和动态链接。
- 这些内容中，`volatile`/`restrict`/`inline` 的基础已经补入，
  但调用约定、动态链接、链接器行为、可移植性还没有练习。

### 狂人 C 程序员入门必备

路径：`.ref/markdown/Algorithms/狂人C程序员入门必备.md`

- 偏基础训练和大量小例子，适合补充“短小但高频”的语法和算法练习。
- 可用来增加类型转换、数组、字符串、循环、函数和指针的重复训练。

### C 语言深度解剖

路径：`.ref/markdown/Algorithms/C语言深度解剖(完美高清文字版).md`

- 按关键字、符号、预处理、指针和数组、内存管理、函数、文件结构组织。
- 当前项目的 `01`-`09` 主题大量参考了这本书。
- 书中的 `auto`、`register`、`static`、`sizeof`、`const`、`volatile`、
  `extern`、`struct`、`union`、`enum`、`typedef` 已经基本覆盖。
- 书中的“文件结构”和“编码风格”提示还需要一个项目型练习，而不仅是
  单文件练习。

## 总体判断

把书和参考仓库放在一起看，`clings` 已经完成了“语言入门 + 指针/内存
基础 + 预处理器 + 基础标准库 + 基础 UB”的闭环。下一步最值得补的是：

1. 多翻译单元和链接；
2. 标准库深度；
3. 分配器和数据结构；
4. POSIX 文件/进程/信号/套接字；
5. 调试、测试、构建和性能工具；
6. 安全、可移植性和现代 C/C23。

详细缺口和优先级见 [gap-analysis.md](gap-analysis.md)。
