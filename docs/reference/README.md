# Reference book

The file `c-language-deep-dissection.md` is a searchable Markdown conversion
of the supplied PDF `C语言深度解剖(完美高清文字版).pdf`.

The conversion is generated with:

```sh
python3 tools/pdf_to_markdown.py
```

The original PDF is the authoritative source for layout, figures, tables, and
code snippets.  The Markdown file is used for full-text search and for mapping
book chapters to clings exercises.

The book is distributed by its author as a free electronic edition.  It is not
relicensed by this repository; see the PDF's own copyright statement.
