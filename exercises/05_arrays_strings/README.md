# Arrays and Strings

Run an exercise with:

```sh
./clings run 01_array_basics
```

| Exercise | Objective | Reference |
| --- | --- | --- |
| `01_array_basics` | Iterate over an array and compute a sum and maximum. | 第四章 4.2 数组 |
| `02_array_decay` | See how an array parameter becomes a pointer. | 第四章 4.3 指针与数组之间的恩恩怨怨 |
| `03_multidimensional` | Transpose a 3x3 matrix with nested loops. | 第四章 4.5 多维数组与多级指针 |
| `04_string_literals` | Scan a const string and modify a mutable char array. | 第四章 4.2 数组；第二章 2.3 单引号、双引号 |
| `05_string_ops` | Implement strlen, strcmp, and strcpy with pointers. | 第四章 4.3 指针与数组；第六章 6.4.2 strlen |
| `06_safe_format` | Format text into a fixed-size buffer without overflow. | 第三章 3.1 宏定义；标准库 printf 资料 |
| `07_tokenize` | Split a string without modifying the caller's buffer. | 第五章 内存管理；标准库 string.h 资料 |
