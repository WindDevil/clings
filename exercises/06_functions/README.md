# Functions and Scope

Run an exercise with:

```sh
./clings run 01_declaration_definition
```

| Exercise | Objective |
| --- | --- |
| `01_declaration_definition` | Use a forward declaration and an internal helper. |
| `02_parameters_return` | Return values through parameters and clamp a range. |
| `03_pass_by_pointer` | Modify caller-owned data through pointers. |
| `04_recursion` | Write recursive functions with correct base cases. |
| `05_static_inline` | Use static functions and file-scope state. |
| `06_function_pointers` | Store functions in variables and choose one at runtime. |
| `07_void_and_return` | Return early from a void function and return values from int functions. |
| `08_tail_recursion` | Rewrite a recursive sum using an accumulator. |
| `09_default_argument_promotions` | Use the promoted types expected by variadic functions. |
| `10_main_return_value` | Return a defined success or failure status from a program. |
