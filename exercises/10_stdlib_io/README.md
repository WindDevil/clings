# Standard Library and File I/O

Run an exercise with:

```sh
./clings run 01_printf_formats
```

| Exercise | Objective |
| --- | --- |
| `01_printf_formats` | Match each conversion specifier to its argument type. |
| `02_scanf_parse` | Parse a comma-separated pair with sscanf. |
| `03_strtol_errno` | Use strtol, errno, and the end pointer to validate input. |
| `04_qsort_bsearch` | Use comparison callbacks for sorting and searching. |
| `05_math_functions` | Use hypot and other functions from math.h. |
| `06_time_functions` | Use time_t and difftime. |
| `07_random` | Seed the generator and bound its output. |
| `08_file_io` | Write and read a text file with fopen, fputs, and fread. |
| `09_memory_functions` | Use the byte-oriented memory functions correctly. |
| `10_string_search` | Use strchr, strrchr, and strstr. |
| `11_stdint_inttypes` | Use uint64_t and PRIu64 from stdint.h and inttypes.h. |
| `12_environment` | Read and write environment variables with getenv and setenv. |
| `13_printf_advanced` | Use width, zero padding, precision, and the * width argument. |
| `14_scanf_advanced` | Use field width and a scanset in sscanf. |
| `15_ctype_full` | Use isalnum and toupper with unsigned char casts. |
| `16_rand_max` | Do not assume rand() returns a value below a fixed small bound. |
