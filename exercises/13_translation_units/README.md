# Translation Units, Headers, and Linkage

Run an exercise with:

```sh
./clings run 01_header_source_split
```

| Exercise | Objective | Reference |
| --- | --- | --- |
| `01_header_source_split` | Compile a program from a main file, a header, and an implementation file. | C Primer Plus 第9章 9.4、第16章 16.5 |
| `02_extern_linkage` | Declare a global variable in a header and define it in another file. | C Primer Plus 第12章 12.1.7、12.1.9 |
| `03_static_internal_linkage` | Keep a counter private to one translation unit with static. | C Primer Plus 第12章 12.1.8-12.1.9 |
| `04_external_type_check` | Keep declarations and definitions consistent across translation units. | C 陷阱与缺陷 4.5 |
| `05_dynamic_linking` | Load a symbol from a shared library at runtime. | C 专家编程 第5章 |
