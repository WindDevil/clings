# Character I/O and Input Validation

Run an exercise with:

```sh
./clings run 01_getc_putc
```

| Exercise | Objective | Reference |
| --- | --- | --- |
| `01_getc_putc` | Copy a stream one character at a time with getc and putc. | C Primer Plus 第8章 8.1、第13章 13.2.3 |
| `02_eof_ferror` | Read until EOF and distinguish end-of-file from an error. | C Primer Plus 第8章 8.3、第13章 13.7.7 |
| `03_input_validation` | Reject input with trailing characters or out-of-range values. | C Primer Plus 第8章 8.6 |
| `04_iso646` | Use and/or/not from iso646.h. | C Primer Plus 第7章 7.3.1 |
| `05_getchar_putchar` | Use the standard input/output character macros directly. | C 陷阱与缺陷 5.1；C Primer Plus 第8章 |
