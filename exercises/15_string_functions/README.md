# String Functions and Conversion

Run an exercise with:

```sh
./clings run 01_strcat_strncat
```

| Exercise | Objective |
| --- | --- |
| `01_strcat_strncat` | Append a string while respecting the destination size. |
| `02_strncpy_bounded` | Copy a string safely and always terminate the destination. |
| `03_sprintf_snprintf` | Format text with snprintf and understand truncation. |
| `04_fgets_fputs_sort` | Read a line with fgets and sort an array of strings. |
| `05_strtod` | Parse a double with strtod and reject trailing input. |
