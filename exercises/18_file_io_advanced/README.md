# Advanced File I/O

Run an exercise with:

```sh
./clings run 01_fprintf_fscanf
```

| Exercise | Objective | Reference |
| --- | --- | --- |
| `01_fprintf_fscanf` | Write formatted data to a file and read it back. | C Primer Plus 第13章 13.4.1 |
| `02_fgets_fputs` | Copy a text file line by line. | C Primer Plus 第13章 13.4.2 |
| `03_getc_putc_ungetc` | Peek at a character and put it back into the stream. | C Primer Plus 第13章 13.2.3、13.7.1 |
| `04_fseek_ftell` | Seek to a byte offset and report the resulting position. | C Primer Plus 第13章 13.5 |
| `05_fflush_setvbuf` | Configure full buffering and flush a stream. | C Primer Plus 第13章 13.7.2-13.7.3 |
| `06_binary_random_access` | Read a specific struct record from a binary file. | C Primer Plus 第13章 13.7.9 |
