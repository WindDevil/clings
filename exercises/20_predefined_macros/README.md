# Predefined Macros

Run an exercise with:

```sh
./clings run 01_stdc
```

| Exercise | Objective |
| --- | --- |
| `01_stdc` | Use __STDC__ to detect a conforming C implementation. |
| `02_stdc_version` | Read the C standard version from __STDC_VERSION__. |
| `03_stdc_hosted` | Distinguish hosted and freestanding implementations. |
| `04_file` | Use __FILE__ to obtain the current source file name. |
| `05_line` | Use __LINE__ to obtain the current source line number. |
| `06_func` | Use __func__ to obtain the current function name. |
| `07_date_time` | Read the compilation date and time. |
| `08_optional_features` | Detect unavailable optional C features with __STDC_NO_* macros. |
